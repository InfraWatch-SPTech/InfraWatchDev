Receber alertas via plataformas externas

Token de API

O Token de API é o código que permite criar uma Issue no Jira com seu e-mail para gerar alertas por você.

Como conseguir?

  1. Na sua conta Jira, entre em Configurações da conta.
  2. Acesse a aba de Segurança.
  3. Em Tokens de API, acesse Gerenciar Tokens de API.
  4. Verifique seu e-mail.
  5. Crie um Token de API.

Teste de credenciais

Após atualizar suas credenciais, é importante que você as teste para garantir a efetividade dos alertas. Enviaremos uma mensagem de teste que confirma que a integração está funcionando.
