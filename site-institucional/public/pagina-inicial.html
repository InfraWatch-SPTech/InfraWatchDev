COMO CONFIGURAR SEU SISTEMA INFRAWATCH

PRIMEIROS PASSOS

COMO FUNCIONA NOSSO SISTEMA?

O sistema InfraWatch funciona de uma forma bem simples. Para adotar a nossa solução você precisará seguir um fluxo para acessar as funcionalidades da nossa solução. Seguindo esse passo a passo você estará pronto para conseguir aderir à nossa solução da melhor forma!

ETAPA 01

CONECTANDO SERVIDOR

01.
CADASTRE UM SERVIDOR

Na área de servidores, informe os dados da máquina que deseja monitorar.

Guarde o código! Ele será necessário novamente no passo 4.

O que significa esse código? O código é como uma senha do seu servidor. É ele que diz à nossa solução qual é o seu servidor e se ele realmente existe. Cada servidor tem um código único.
02.
DEFINA OS PARÂMETROS DE ALERTA

Para cada componente que desejar monitorar do seu servidor defina um parâmetro (gatilho), onde quando o gatilho for atingido um alerta será gerado.

Esse passo é obrigatório! Você poderá alterar os valores dos parâmetros depois na aba "Servidores".
03.
FAÇA O DOWNLOAD DO SCRIPT DE CAPTURA

Faça o download do Script de captura para recebimento dos dados do seu servidor.

O que é o script de captura? O Script de captura é um arquivo python que será utilizado para capturar os dados que alimentarão a dashboard do seu servidor. Você pode baixar clicando no botão abaixo:
04.
EXECUTE O SCRIPT.PY NO SERVIDOR

O arquivo que você fez download no passo anterior deve ser executado em seu servidor. Durante ele deve-se informar suas credenciais conforme as credenciais cadastradas no site.

Código: O código cadastrado no servidor deve ser o mesmo digitado no script de captura.
05.
VISUALIZE OS DADOS DO SEU SERVIDOR NA DASHBOARD

Pronto! Agora o monitoramento do seu servidor está configurado, liberando o acesso às dashboards e gerenciamento.

ETAPA 02

CONEXÃO DE ALERTAS AUTOMÁTICOS

Antes de começar você deve ter ao menos um servidor com parâmetros configurados.
01.
ACESSE A PLATAFORMA DE ALERTAS

Abra o menu lateral do site e clique em Plataforma de Alerta.

02.
CONEXÃO COM O JIRA

Para conseguir receber alertas pelo Jira você deve preencher os campos de conexão:

  • Link do espaço: O endereço do seu Jira, no formato https://sua-empresa.atlassian.net
  • E-mail: O e-mail da sua conta Atlassian.
  • Token de API: O passo a passo é explicado na caixa ao lado.
Segurança: O token de API funciona como uma senha, não o compartilhe!
03.
RECEBA ALERTAS AUTOMATICAMENTE

Pronto, sua configuração de alertas está concluída! Quando um componente atingir o parâmetro definido, a InfraWatch cria uma tarefa no Jira.
